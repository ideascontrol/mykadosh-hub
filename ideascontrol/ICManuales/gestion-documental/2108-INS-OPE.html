01Objetivo

Establecer el procedimiento para realizar la conexión física Ethernet y verificar la conectividad de red de un dispositivo biométrico, garantizando su correcta comunicación con el servidor de integración y/o la plataforma de tiempos y asistencia.

02Alcance

Aplica a:

  • Instalaciones nuevas de dispositivos biométricos.
  • Reemplazo o reinstalación de equipos.
  • Visitas de soporte relacionadas con fallas de comunicación por red cableada.
  • Validaciones posteriores a mantenimiento.

03Responsabilidades

Técnico instalador o de soporte

  • Realizar la conexión física del cableado Ethernet.
  • Configurar los parámetros de red del dispositivo.
  • Verificar la conectividad.
  • Registrar la evidencia correspondiente.

Cliente

  • Proporcionar el punto de red habilitado.
  • Garantizar la disponibilidad de la infraestructura de red.
  • Autorizar las pruebas de conectividad cuando sea requerido.

04Requisitos previos

Antes de iniciar se debe contar con:

  • Dispositivo biométrico instalado y energizado.
  • Punto de red Ethernet operativo.
  • Cable UTP categoría 5e o superior en buen estado.
  • Información de red suministrada por el cliente:
  • Dirección IP fija o reserva DHCP.
  • Máscara de red.
  • Puerta de enlace.
  • DNS (si aplica).

05Materiales y herramientas

  • Cable UTP.
  • Probador de red (opcional).
  • Equipo portátil para pruebas.
  • Herramientas básicas de instalación.

06Procedimiento

  1. 01
    Verificación del punto de red
  • Validar topología de red y políticas de seguridad de esta.
  • Verificar continuidad del cableado cuando sea posible.
  • Confirmar con el cliente que el puerto del switch esté habilitado.
  1. 02
    Conexión física
  • Conectar un extremo del cable UTP al puerto Ethernet del dispositivo biométrico.
  • Conectar el otro extremo al punto de red del cliente.
  • Verificar que el conector quede firmemente asegurado.
  1. 03
    Verificación del enlace físico

Observar los indicadores LED del puerto Ethernet del biométrico.

Estado LEDInterpretación
Encendido fijoEnlace físico establecido
IntermitenteTráfico de datos presente
ApagadoSin enlace físico

Si el LED permanece apagado:

  • Revisar el cable UTP.
  • Probar otro puerto de red.
  • Verificar habilitación del puerto del switch.
  1. 04
    Configuración de red del dispositivo

Ingresar al menú del biométrico:

Menú → Red / Network → TCP/IP

Configurar según la información suministrada por el cliente:

Guardar los cambios y reiniciar el servicio de red si el equipo lo solicita.

  1. 05
    Verificación de conectividad

Desde un computador conectado a la misma red ejecutar una prueba de ping hacia la IP del biométrico, siguiendo el instructivo 2107-INS-OPE – Instructivo prueba de conectividad Ping.

Resultado esperado

Respuesta satisfactoria sin pérdida de paquetes.

  1. 06
    Verificación de comunicación con el servidor

Cuando aplique, validar que el dispositivo pueda comunicarse con:

  • Servidor WFM.
  • Servidor de integración.
  • Plataforma de tiempos y asistencia.

Realizar prueba de sincronización o transmisión de marcaciones.

07Criterios de aceptación

La conexión Ethernet se considera satisfactoria cuando:

  • El LED de enlace permanece activo.
  • El equipo responde al ping.
  • La pérdida de paquetes es 0 %.
  • La sincronización con el servidor es exitosa.
  • No se presentan desconexiones durante la prueba.

08Manejo de fallas

Si la falla persiste, escalar a Nivel 2 de Ideas Control o al área de redes del cliente.

09Evidencia y registro

Registrar en el checklist o ticket:

  • Fecha y hora.
  • Nombre del técnico.
  • Punto de red utilizado.
  • Dirección IP configurada.
  • Estado del enlace físico.
  • Resultado del ping.
  • Resultado de sincronización.
  • Observaciones.

10Seguridad y buenas prácticas

  • No utilizar cables dañados.
  • Mantener separación del cableado eléctrico.
  • Etiquetar el cable de red cuando aplique.
  • No modificar configuraciones de red del cliente sin autorización.
  • Mantener ordenado y protegido el cableado instalado.
