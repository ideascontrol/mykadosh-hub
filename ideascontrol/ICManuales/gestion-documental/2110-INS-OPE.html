01Objetivo

Establecer el procedimiento para realizar el enrolamiento de un empleado en un dispositivo biométrico ZKTeco SpeedFace-V5L, garantizando que el usuario quede correctamente identificado, que el método de autenticación seleccionado funcione y que, cuando aplique, la información pueda ser asociada y sincronizada con la plataforma de Tiempos y Asistencia / WFM.

02Alcance

Este instructivo aplica al enrolamiento de empleados en dispositivos ZKTeco SpeedFace-V5L utilizados por Ideas Control como parte de soluciones de control y gestión de tiempos y asistencia.

Contempla el registro mediante:

  • Reconocimiento facial.
  • Huella digital, cuando el modelo instalado cuente con sensor de huella.
  • Tarjeta, cuando el equipo disponga del módulo correspondiente.
  • Contraseña/PIN, cuando este método esté habilitado.
  • Palma cuando el equipo disponga del módulo correspondiente.

El procedimiento deberá adaptarse a las funcionalidades disponibles en la versión específica del equipo instalado.

03Requisitos previos

Antes de iniciar el enrolamiento, el técnico deberá confirmar:

  • El dispositivo se encuentra instalado y energizado.
  • La fecha y hora del dispositivo son correctas.
  • La zona horaria corresponde a la ubicación de la sede.
  • El dispositivo se encuentra correctamente conectado a la red cuando la prueba incluya integración con el software.
  • Se dispone del identificador del empleado que será utilizado en el dispositivo.
  • El empleado ha sido previamente autorizado por el responsable del cliente.
  • Se ha definido el método de identificación que será utilizado.
  • El técnico cuenta con permisos administrativos para realizar el enrolamiento.
  • El equipo no presenta errores de funcionamiento.

04Información del empleado

Antes de iniciar, el técnico deberá contar con la información mínima necesaria para identificar al empleado.

05Consideraciones de seguridad y protección de datos

Antes de realizar el enrolamiento, deberá verificarse que el empleado se encuentre autorizado para ser registrado.

Cuando se utilicen datos biométricos, el tratamiento deberá realizarse conforme a:

  • 4100-POL-TEC Política de Seguridad y Protección de la Información.
  • Las políticas de protección de datos aplicables.
  • Las condiciones contractuales definidas con el cliente.
  • La normativa vigente aplicable al tratamiento de datos personales.

El técnico deberá:

  • Registrar únicamente la información necesaria.
  • No tomar fotografías del rostro del empleado como evidencia del enrolamiento, salvo autorización y necesidad justificada.
  • No copiar ni extraer plantillas biométricas.
  • No almacenar huellas, fotografías, plantillas faciales u otra información biométrica en computadores personales.
  • No enviar información biométrica por correo, WhatsApp u otros medios no autorizados.
  • No utilizar información biométrica del cliente para actividades diferentes a las autorizadas.

06Acceso al menú de usuarios

Para realizar el enrolamiento:

  • Acceder al menú administrativo del dispositivo.
  • Autenticarse utilizando una cuenta autorizada.
  • Ingresar a la sección de Gestión de Usuarios / User Management o equivalente.
  • Seleccionar la opción para agregar o registrar un nuevo usuario.

Nota: La denominación exacta de los menús puede variar según la versión de firmware instalada en el SpeedFace-V5L. En caso de diferencia, deberá utilizarse el manual vigente correspondiente a la versión del equipo.

07Creación del usuario

Al crear el usuario, ingresar la información correspondiente.

Como mínimo deberá configurarse:

ID de usuario

Asignar el código o identificador único del empleado.

El ID deberá:

  • Ser único dentro del dispositivo.
  • Coincidir con el identificador definido en la solución WFM, cuando aplique.
  • Cumplir con las restricciones de longitud y formato del sistema.

El SpeedFace-V5L soporta identificadores de usuario de hasta 14 dígitos, de acuerdo con la especificación actual del fabricante.

Nombre

Registrar el nombre del empleado cuando la configuración del proyecto requiera que este sea almacenado en el dispositivo.

Método de identificación

Seleccionar el método que será utilizado:

  • Face.
  • Fingerprint.
  • Card.
  • Password.

No deberán configurarse métodos adicionales que no estén contemplados en el alcance del servicio.

08Enrolamiento facial

El SpeedFace-V5L incorpora reconocimiento facial y permite registrar plantillas faciales para identificación de usuarios.

Para realizar el enrolamiento:

  • Seleccionar el usuario previamente creado.
  • Seleccionar la opción Face / Rostro.
  • Ubicar al empleado frente al dispositivo.
  • Solicitar al empleado que mantenga el rostro dentro del área indicada por el equipo.
  • Mantener una posición natural y estable durante la captura.
  • Seguir las indicaciones mostradas en pantalla.
  • Esperar a que el dispositivo complete el proceso de registro.
  • Confirmar que el equipo indique que el enrolamiento fue exitoso.
  • Guardar la información del usuario.

09Condiciones recomendadas

Durante el registro:

  • El rostro deberá estar claramente visible.
  • Evitar obstrucciones que puedan afectar la captura.
  • Evitar contraluz o iluminación excesivamente intensa.
  • Mantener al empleado frente al dispositivo.
  • Evitar movimientos innecesarios durante la captura.

El SpeedFace-V5L utiliza una cámara binocular de 2 MP WDR para reconocimiento facial.

10Validación del reconocimiento facial

Una vez finalizado el enrolamiento:

  • Salir del menú administrativo.
  • Solicitar al empleado ubicarse frente al dispositivo.
  • Realizar una primera identificación.
  • Verificar que el dispositivo reconozca al empleado.
  • Realizar una segunda identificación para confirmar consistencia.
  • Confirmar que el usuario identificado corresponde al ID registrado.

Resultado esperado

El dispositivo deberá:

  • Reconocer al empleado.
  • Mostrar o identificar correctamente el usuario.
  • Generar el evento correspondiente.
  • No presentar errores durante la autenticación.

Si el reconocimiento falla repetidamente, no se deberán realizar registros indiscriminados. Se deberá revisar primero la calidad del enrolamiento, posición del usuario, iluminación, configuración del dispositivo y demás condiciones de operación.

11Enrolamiento de huella digital

Cuando el dispositivo instalado cuente con sensor de huella:

  • Seleccionar el usuario.
  • Seleccionar la opción Fingerprint / Huella.
  • Seleccionar el dedo que será registrado.
  • Solicitar al empleado colocar el dedo sobre el sensor siguiendo las indicaciones del dispositivo.
  • Repetir la captura las veces que el equipo solicite.
  • Confirmar que el registro haya sido completado correctamente.
  • Guardar el registro.
  • Realizar una identificación de prueba.

Se recomienda registrar una huella que pueda ser utilizada cómodamente por el empleado durante la operación diaria.

La versión SpeedFace-V5L estándar soporta hasta 10.000 huellas y utiliza tecnología ZKFingerprint según la especificación del fabricante.

12Validación de huella

Realizar como mínimo dos pruebas de identificación.

Verificar:

  • Reconocimiento correcto.
  • Correspondencia con el usuario.
  • Ausencia de errores.
  • Generación correcta del evento.
  • Tiempo de respuesta adecuado.

Si el usuario presenta dificultades recurrentes para ser identificado, revisar:

  • Calidad del enrolamiento.
  • Posición del dedo.
  • Limpieza del sensor.
  • Estado de la huella.
  • Configuración del dispositivo.

Cuando sea necesario, realizar nuevamente el enrolamiento siguiendo el procedimiento del fabricante.

13Enrolamiento mediante tarjeta

Cuando el dispositivo cuente con el módulo de tarjeta correspondiente:

  • Seleccionar el usuario.
  • Seleccionar la opción Card / Tarjeta.
  • Aproximar o presentar la tarjeta al lector.
  • Esperar a que el dispositivo detecte el identificador.
  • Confirmar la asociación de la tarjeta al usuario.
  • Guardar la configuración.
  • Realizar una prueba de identificación.

El tipo de tarjeta compatible dependerá de la variante específica del SpeedFace-V5L instalada. El fabricante contempla diferentes opciones de módulos RFID según la versión del equipo.

14Enrolamiento mediante contraseña / PIN

Cuando este método se encuentre habilitado:

  • Seleccionar el usuario.
  • Seleccionar la opción Password / Contraseña.
  • Definir el PIN de acuerdo con las políticas establecidas.
  • Confirmar la contraseña.
  • Guardar la configuración.
  • Realizar una prueba de autenticación.

Los PIN o contraseñas no deberán registrarse en el checklist, acta de instalación ni evidencias fotográficas.

15Validación del identificador del empleado

Antes de realizar la integración con el software, verificar que:

ID del dispositivo = ID del empleado en WFM

Cuando el software utilice un identificador diferente, deberá existir una correspondencia documentada entre ambos.

Ejemplo:

SistemaIdentificador
Empleado000125
Biométrico000125
WFM000125

Si los identificadores no coinciden, deberá aplicarse el mecanismo de correspondencia definido por la plataforma.

16Prueba de marcación

Una vez validado el método de identificación:

  • Solicitar al empleado realizar una marcación.
  • Confirmar que el dispositivo acepte la identificación.
  • Verificar que se genere el evento.
  • Registrar la hora de la prueba.
  • Confirmar posteriormente la recepción de la marcación en la plataforma WFM, cuando aplique.

El flujo esperado es:

Empleado → Identificación → Biométrico → Red → Plataforma → Marcación

17Validación en la plataforma de WFM

Cuando el dispositivo esté integrado con la plataforma de Tiempos y Asistencia:

  • Consultar la plataforma.
  • Buscar el empleado mediante su identificador.
  • Localizar la marcación realizada.
  • Confirmar fecha y hora.
  • Confirmar que el empleado asociado sea correcto.
  • Confirmar que el dispositivo de origen corresponda al instalado.
  • Verificar que no se haya generado una marcación duplicada o incorrecta.

Si la marcación no aparece en la plataforma, deberá iniciarse el diagnóstico de integración antes de declarar satisfactorio el enrolamiento.

18Prueba completa de extremo a extremo

El enrolamiento se considerará técnicamente validado cuando se pueda comprobar el siguiente flujo:

20Eliminación de usuarios de prueba

Cuando el usuario haya sido creado exclusivamente para pruebas:

  • Confirmar con el responsable del cliente si debe conservarse.
  • Si no debe conservarse, eliminar el usuario del dispositivo.
  • Eliminar la asociación correspondiente en el software cuando aplique.
  • Verificar que no queden registros temporales innecesarios.
  • Registrar la acción en el checklist.

Cuando el usuario pase a producción, no deberá crearse nuevamente sin necesidad. Se deberá validar que el registro existente corresponda al empleado correcto.

21Criterios de aceptación

El enrolamiento se considera satisfactorio cuando:

  • El empleado fue autorizado para el registro.
  • El usuario fue creado correctamente.
  • El ID es correcto.
  • El método de identificación funciona.
  • El empleado puede identificarse correctamente.
  • Se genera una marcación.
  • La marcación es transmitida cuando existe integración.
  • La marcación aparece asociada al empleado correcto.
  • Fecha y hora son correctas.
  • No existen duplicidades o inconsistencias.
  • El resultado fue registrado en el formato correspondiente.

23Responsabilidades

Técnico de Ideas Control

  • Verificar los requisitos previos.
  • Ejecutar el enrolamiento.
  • Realizar las pruebas.
  • Validar la marcación.
  • Registrar los resultados.
  • Proteger la información utilizada durante la actividad.

Responsable del cliente

  • Autorizar al empleado.
  • Facilitar su disponibilidad.
  • Validar el resultado cuando corresponda.
  • Informar cualquier inconsistencia en la identificación del empleado.
