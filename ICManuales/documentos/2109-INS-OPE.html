01Objetivo

Establecer el procedimiento para configurar y validar la conexión WiFi de dispositivos biométricos cuando no se disponga de conexión Ethernet, garantizando una comunicación estable con el servidor de integración y/o la plataforma de tiempos y asistencia.

02Alcance

Aplica a:

  • Instalaciones nuevas con conectividad inalámbrica.
  • Reubicación de dispositivos biométricos.
  • Reconfiguración de red WiFi.
  • Actividades de soporte relacionadas con conectividad inalámbrica.

03Responsabilidades

Técnico instalador o de soporte

  • Configurar la conexión WiFi del dispositivo.
  • Verificar la estabilidad de la comunicación.
  • Registrar la configuración y evidencias correspondientes.

Cliente

  • Proporcionar las credenciales de red autorizadas.
  • Garantizar cobertura inalámbrica adecuada en el punto de instalación.
  • Autorizar el acceso a la red corporativa cuando sea requerido.

04Requisitos previos

Antes de iniciar, se debe contar con:

  • Dispositivo biométrico instalado y energizado.
  • Cobertura WiFi disponible en el punto de instalación.
  • Información suministrada por el cliente:
  • Nombre de la red (SSID).
  • Contraseña.
  • Tipo de seguridad (WPA2/WPA3).
  • Método de direccionamiento (DHCP o IP fija).
  • Confirmación de que el SSID se encuentra habilitado para nuevos dispositivos.

05Consideraciones de seguridad

  • Las credenciales WiFi son confidenciales y no deben divulgarse.
  • No almacenar contraseñas en dispositivos personales del técnico.
  • Utilizar únicamente redes autorizadas por el cliente.
  • No modificar políticas de seguridad inalámbrica del cliente sin aprobación.

06Procedimiento

07Verificar cobertura inalámbrica

  • Hay que confirmar que exista señal WiFi en el punto de instalación.
  • Validar, preferiblemente con un dispositivo móvil o portátil, que la intensidad de señal sea suficiente para operación continua.

Referencia recomendada: intensidad mayor a -70 dBm.

08Ingresar al menú de red del dispositivo

Acceder al menú:

Menú → Red / Network → WiFi

Activar la interfaz inalámbrica si se encuentra deshabilitada.

09Buscar redes disponibles

  • Seleccionar Buscar / Scan.
  • Esperar la detección de redes.
  • Identificar el SSID suministrado por el cliente.

10Conectar a la red

  • Seleccionar el SSID correspondiente.
  • Ingresar la contraseña proporcionada por el cliente.
  • Confirmar el tipo de seguridad cuando el equipo lo solicite.
  • Guardar la configuración.

11Configurar direccionamiento IP

Opción A – DHCP

Seleccionar Obtener IP automáticamente.

Opción B – IP fija

Ingresar:

ParámetroValor
Dirección IP
Máscara de red
Puerta de enlace
DNS

12Verificar conexión

Confirmar en la pantalla del dispositivo:

  • Estado: Conectado
  • Dirección IP asignada.
  • Intensidad de señal.
  • SSID conectado.

13Verificar comunicación de red

Desde un computador conectado a la misma red ejecutar una prueba de ping hacia la IP del biométrico, siguiendo el instructivo 2107-INS-OPE Instructivo prueba conectividad Ping.

14Verificar comunicación con el servidor

Cuando aplique, validar sincronización o transmisión de marcaciones hacia:

  • Servidor WFM.
  • Servidor de integración.
  • Plataforma de tiempos y asistencia.

15Criterios de aceptación

La configuración WiFi se considera satisfactoria cuando:

  • El dispositivo permanece conectado al SSID autorizado.
  • Obtiene dirección IP válida.
  • Responde correctamente al ping.
  • La pérdida de paquetes es 0 %.
  • La señal es estable.
  • La sincronización con el servidor es exitosa.

16Manejo de fallas communes

SíntomaAcción recomendada
SSID no visibleVerificar cobertura y habilitación del SSID
Contraseña incorrectaConfirmar credenciales con el cliente
No obtiene IPRevisar DHCP o configurar IP fija
Señal débilReubicar equipo o instalar punto de acceso
Desconexiones frecuentesVerificar interferencias y calidad de señal
Sin comunicación con servidorRevisar firewall, VLAN o rutas de red

Si la falla persiste, escalar a Nivel 2 de Ideas Control o al área de redes del cliente.

17Evidencia y registro

Registrar en el checklist o ticket:

  • Fecha y hora.
  • Nombre del técnico.
  • SSID configurado.
  • Método IP (DHCP o fija).
  • Dirección IP obtenida.
  • Intensidad de señal.
  • Resultado del ping.
  • Resultado de sincronización.
  • Observaciones.

18Buenas prácticas

  • Preferir Ethernet cuando exista disponibilidad de cableado.
  • Evitar instalar el equipo cerca de hornos microondas, motores o fuentes de interferencia.
  • Mantener antenas libres de obstrucciones.
  • Documentar cualquier cambio de red realizado durante la instalación.
