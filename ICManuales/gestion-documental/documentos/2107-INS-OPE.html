01Objetivo

Establecer el procedimiento para verificar la conectividad de red entre un dispositivo biométrico y la infraestructura del cliente mediante una prueba de ping, garantizando que el equipo pueda comunicarse correctamente con el servidor de integración y/o la plataforma de tiempos y asistencia.

02Alcance

Aplica a:

  • Instalaciones nuevas de dispositivos biométricos.
  • Reinstalaciones.
  • Visitas de soporte técnico.
  • Diagnósticos de comunicación de red.

03Responsabilidades

Técnico instalador o de soporte

  • Ejecutar la prueba de conectividad.
  • Validar el resultado.
  • Registrar la evidencia en el checklist o ticket correspondiente.

Cliente

  • Proporcionar acceso a la red interna cuando sea requerido.
  • Confirmar disponibilidad del punto de red y direccionamiento IP.

04Requisitos previos

Antes de iniciar la prueba se debe contar con:

  • Dispositivo biométrico energizado.
  • Conexión de red física o inalámbrica establecida.
  • Dirección IP asignada al dispositivo.
  • Equipo de cómputo conectado a la misma red del cliente.
  • Permisos de acceso a la red.

05Procedimiento

  1. 01
    Identificar la dirección IP del dispositivo

Desde el menú del biométrico:

Menú → Red / Network → TCP/IP

Registrar:

  • Dirección IP
  • Máscara de red
  • Puerta de enlace

Ejemplo: 192.168.1.50

  1. 02
    Ejecutar la prueba en Windows
  • Presionar Win + R.
  • Escribir cmd y seleccionar Aceptar.
  • En la ventana de comandos ejecutar:

ping 192.168.1.50

  • Esperar la respuesta.
  • Resultado esperado

Respuesta desde 192.168.1.50: bytes=32 tiempo<1ms TTL=64

  1. 03
    Ejecutar la prueba en Linux o macOS

Abrir la terminal y ejecutar:

ping 192.168.1.50

Detener la prueba con Ctrl + C después de recibir al menos cuatro respuestas.

06Interpretación de resultados

ResultadoInterpretaciónAcción
Respuesta exitosaConectividad correctaContinuar instalación
Tiempo de espera agotadoNo hay comunicaciónRevisar cableado, IP y red
Host inaccesibleProblema de enrutamiento o IPValidar configuración TCP/IP
Pérdida parcial de paquetesComunicación inestableRevisar red física o WiFi

07Acciones de verificación cuando la prueba falla

Realizar las siguientes validaciones:

  • Cable UTP conectado correctamente.
  • Indicadores LED de enlace activos.
  • Dirección IP correcta y sin conflictos.
  • Máscara de red adecuada.
  • Puerta de enlace configurada.
  • Puerto de switch habilitado.
  • Reglas de firewall del cliente.
  • Cobertura WiFi suficiente (si aplica).

08Evidencia y registro

El técnico deberá registrar en el checklist o ticket:

  • Fecha y hora.
  • Nombre del técnico.
  • Dirección IP evaluada.
  • Resultado de la prueba.
  • Número de respuestas recibidas.
  • Observaciones.

09Criterio de aceptación

La prueba se considera satisfactoria cuando:

  • Se reciben respuestas desde la dirección IP del biométrico.
  • La pérdida de paquetes es 0 %.
  • El tiempo de respuesta es estable.
  • El equipo permanece conectado durante la prueba.

10Manejo de incidentes

Si no es posible obtener conectividad después de las verificaciones básicas:

  • Registrar el incidente.
  • Escalar a soporte de red del cliente o a Nivel 2 de Ideas Control.
  • Documentar todas las pruebas realizadas antes de la escalación.

11Seguridad y buenas prácticas

  • No modificar configuraciones de red del cliente sin autorización.
  • No ejecutar pruebas sobre direcciones IP no autorizadas.
  • Mantener confidencialidad de la información de red.
  • Registrar únicamente la información necesaria para soporte técnico.
